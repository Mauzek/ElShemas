# Редактор электрических схем (ТОЭ)

Веб-редактор принципиальных электрических схем для дисциплины «Теоретические основы
электротехники и компьютерной электроники». Работает целиком в браузере: без бэкенда,
без авторизации, без серверных вызовов. Схемы хранятся в `localStorage` и выгружаются
в файлы `.json`, `.svg` и `.png`.

Полотно рисуется инлайновым SVG — не canvas и не сторонним графом, поэтому любая схема
экспортируется в векторный файл ровно в том виде, в каком видна на экране, и остаётся
редактируемой в Inkscape или Word.

## Запуск

```bash
npm install
npm run dev          # http://localhost:5173
```

Сборка и проверки:

```bash
npm run build        # проверка типов + production-сборка в dist/
npm run preview      # локальный просмотр собранной версии
npm run typecheck    # только проверка типов
npm test             # юнит-тесты расчётного ядра
```

Стек: React 18 + TypeScript (strict), Vite 5, Zustand, Tailwind поверх собственных
CSS-переменных, иконки `lucide-react`, `fflate` для схемы в ссылке. Внешних библиотек
рисования, графов и математики нет: решатель цепи написан здесь же.

## Деплой на Vercel

Проект — статическая Vite-сборка, дополнительной настройки не требуется.

1. Залить репозиторий на GitHub и нажать **Import Project** в Vercel, либо
   выполнить `npx vercel --prod` в корне проекта.
2. Vercel читает `vercel.json`: framework `vite`, команда `npm run build`,
   каталог `dist`, все маршруты переписываются на `/`.

## Интерфейс

Полотно занимает всё окно, а интерфейс плавает над ним, как в Figma:

- **слева вверху** — бабл с меню, названием схемы и кнопками отмены/повтора;
- **справа вверху** — «вписать в экран» и экспорт;
- **внизу по центру** — инструменты (выделение, рука, провод, текст, карандаш),
  видимость сетки, привязка, шаг и кнопка расчёта ⚡; панель контекстная:
  у карандаша появляются цвет и толщина, у провода — режим углов;
- **слева и справа** — палитра элементов и панель свойств; палитра сворачивается
  в узкую полосу с одними значками;
- **внизу слева** — строка состояния, **внизу справа** — регулятор масштаба.

Файловые операции собраны в меню-бургере с разделами:

| Раздел | Пункты |
| --- | --- |
| Файл | Новая схема · Открыть файл… · Сохранить как… (`Ctrl+S`) · Поделиться ссылкой… · Мои схемы |
| Экспорт | Экспорт PNG / SVG… (`Ctrl+E`) · Печать (`Ctrl+P`) |
| Схема | Проверка схемы · Список элементов |
| Вид | Светлая / тёмная тема · Горячие клавиши (`?`) |

Действия, которые нельзя отменить или которые что-то выгружают наружу — создание новой
схемы поверх непустой, удаление схемы, скачивание файла — сначала спрашивают
подтверждение в модальном окне, а не выполняются молча.

Разделы палитры помечены цветом, поэтому нужная группа находится взглядом.
Подсказки к кнопкам собственные и появляются почти сразу, а не через секунду,
как браузерные. Горячие клавиши читают физическую клавишу (`event.code`), поэтому
одинаково работают на русской и английской раскладке — `Ctrl+Я` отменяет так же,
как `Ctrl+Z`.

Плавающие панели перекрывают полотно, и редактор об этом знает: «вписать в экран»
и стартовый вид центруют схему по свободной области, а не по всему окну.

## Возможности

### Расчёт цепи постоянного тока

Кнопка ⚡ в нижней панели или `Ctrl+R` — и схема считается сама, при каждом изменении,
с задержкой 150 мс. Пока идёт пересчёт, прежние числа затеняются, а не мигают.

Решатель — **модифицированный метод узловых потенциалов** с LU-разложением и выбором
главного элемента. Идеальные источники ЭДС, перемычки, замкнутые ключи и амперметры
получают собственную переменную тока, поэтому обрабатываются без преобразования
источников. Опорный узел выбирается автоматически (элемент «земля», иначе узел
с наибольшим числом ветвей) и переназначается кликом по узлу на карте потенциалов.

Что показывается прямо на схеме — каждый пункт включается отдельно:

- **токи ветвей** со стрелкой фактического направления; отрицательный ток разворачивает
  стрелку, а не пишет минус (есть опция «показывать знак»);
- **напряжения** с полярностью `+ / −` на выводах;
- **мощности**, причём источники и приёмники различаются цветом подписи;
- **потенциалы узлов** цветом от синего к красному с подписью `φ`;
- **толщина провода пропорциональна току** — видно, где основной ток, а где почти ничего;
- **карточка при наведении** на элемент: R, I, U, P одним взглядом.

Единицы подбираются сами: `0,0025 А` показывается как `2,5 мА`, `15000 Ом` — как `15 кОм`.
Число значащих цифр настраивается.

**Баланс мощностей** — отдельная плашка: сколько отдают источники, сколько потребляют
приёмники и невязка в ваттах и процентах. Это стандартная проверка любой лабораторной.

Как элементы участвуют в расчёте:

| Элемент | Модель в цепи постоянного тока |
| --- | --- |
| Резисторы всех видов | сопротивление |
| Источник ЭДС, источник напряжения, батарея | идеальный источник напряжения |
| Источник тока | идеальный источник тока |
| Катушка индуктивности | перемычка |
| Конденсатор | разрыв |
| Замкнутый ключ, предохранитель, амперметр | перемычка (амперметр показывает ток ветви) |
| Разомкнутый ключ, вольтметр | разрыв (вольтметр показывает напряжение) |
| Земля, узел, клемма | только узел схемы |
| Диоды, транзисторы, трансформаторы, логика | в расчёте не участвуют, о чём сказано в замечаниях |

Схема не обязана быть правильной — редактор объясняет, что не так, и по клику
переходит к виновнику:

- элемент без значения или с непонятным значением;
- контур из идеальных источников ЭДС, у которого сумма ЭДС не равна нулю;
- источник тока, включённый в разрыв: току некуда течь;
- сопротивление, равное нулю, — короткое замыкание ветви;
- несвязанные фрагменты: каждый считается со своим опорным узлом;
- параллельные перемычки, между которыми ток делится неоднозначно.

Ядро расчёта лежит в `src/lib/solver/`, не зависит от интерфейса и покрыто
юнит-тестами на схемах с известным ответом: делитель напряжения, уравновешенный мост,
источник тока на параллельных сопротивлениях, напряжение холостого хода
(эквивалентный генератор), амперметр и разомкнутый ключ, вырожденные схемы.

### Переменные и выражения

В значении элемента можно писать не только число:

- **инженерные приставки** обеих раскладок: `2.2k`, `2,2к`, `4м7` (это 0,0047), `10 мкФ`;
- **выражения**: `2*R`, `sqrt(2)*100`, `Rn/3`, со скобками, степенью и функциями
  `sqrt`, `abs`, `sin`, `cos` и константой `pi`. Никакого `eval` — свой разборщик;
- **переменные схемы** задаются в панели «Переменные»: имя и значение, которое само
  может быть выражением. Поменяли `R` — пересчиталась вся схема.

Циклические ссылки (`A = B`, `B = A`) обнаруживаются и показываются ошибкой,
а не зацикливают приложение. Переменные хранятся в файле схемы, поэтому один
файл держит целый вариант задания.

### Ссылка на схему и режим просмотра

«Меню → Поделиться ссылкой…» упаковывает схему в саму ссылку: документ сжимается
и кладётся в **хеш** адреса, а хеш браузер на сервер не отправляет. Ничего никуда
не загружается, аккаунт не нужен.

- Схема на 6 элементов укладывается примерно в 600 символов; предел — 8000,
  и при его превышении редактор честно предлагает отправить файлом.
- Открывший ссылку видит схему целиком (вид подгоняется сам) и баннер:
  пока схему не сохранили кнопкой, она не попадает в «Мои схемы» — библиотека
  не забивается всем, что когда-либо открывали.
- Галочка **«только просмотр»** даёт ссылку вида `?view=1`: палитра, панель свойств
  и инструменты скрыты, схему можно только смотреть и масштабировать.
  Кнопка «Открыть в редакторе» переносит ту же схему в полный редактор.
- Настройки расчёта хранятся в документе, поэтому по ссылке уезжает не только схема,
  но и посчитанные токи с напряжениями.

### Полотно и навигация

- Бесконечное полотно: границ у координатной сетки нет, схема растёт в любую сторону.
- Масштаб **25 %–400 %**: колесо мыши приближает к позиции курсора (точка под
  курсором остаётся на месте), `Ctrl+0` возвращает 100 %, `Ctrl+1` вписывает схему.
- Панорамирование: средняя кнопка мыши, пробел с перетаскиванием или инструмент «Рука» (`H`).
- Регулятор масштаба в правом нижнем углу: `−`, текущий процент (клик — 100 %), `+`,
  «вписать в экран».
- Вписывание не раздувает мелкую схему во весь экран — потолок 200 %.
- Точечная сетка с независимыми переключателями: **видимость** (`Shift+G`) и
  **привязка** (`G`). Шаг — 10, 20 или 40 px, выбирается выпадающим списком в нижней панели.
- Строка состояния показывает координаты курсора в узлах сетки, число элементов
  и проводов, количество электрических узлов и активный инструмент. При узком окне
  чипы прячутся по одному, самое важное остаётся.

### Библиотека УГО

44 условных графических обозначения по ГОСТ 2.721–2.759, восемь категорий:
пассивные, источники, измерительные, коммутация, полупроводники, логические, блоки,
аннотации. Каждая категория окрашена своим цветом и сворачивается.

- Поиск по названию, ключевым словам и префиксу обозначения: «зажим», «кружок»,
  «node», «FU», «двухполюсник» находят нужный символ.
- Превью символа рисуется тем же компонентом, что и на схеме, — что видно в палитре,
  то и появится на полотне.
- Символы источников выполнены в варианте, принятом в методичках ТОЭ: кружок со
  стрелкой для ЭДС, кружок с двойным шевроном для источника тока.
- Взаимная индуктивность рисуется с точками начала обмоток.
- Стиль катушки переключается глобально: прямоугольник (ГОСТ) или дуги.

### Размещение элементов

- Клик по символу в палитре включает режим размещения: за курсором следует
  полупрозрачный призрак, привязанный к сетке.
- Прямо во время размещения работают `R` (поворот на 90°), `Shift+R` (на 45°)
  и `F` (зеркало) — элемент ставится уже в нужной ориентации.
- Символ можно перетащить из палитры на полотно мышью.
- `Esc` или правая кнопка мыши отменяют размещение.
- Обозначение назначается автоматически и отдельно по каждому префиксу:
  `R1, R2, …` независимо от `E1, E2, …`, `J`, `C`, `L`, `FU`. Учитываются штрихи,
  поэтому `R′4` не мешает нумерации `R5`.
- Выводы двухполюсников отстоят от якоря на 40 px, поэтому при любом из трёх шагов
  сетки они всегда попадают в её узлы.

### Редактирование и свойства

- Двойной клик по элементу открывает инлайновый редактор обозначения прямо на схеме,
  `Tab` переводит к значению, `Enter` подтверждает.
- Панель свойств справа: обозначение, значение, единица, показывать ли значение,
  поворот (список 0…315° плюс кнопки поворота и зеркала), направление для элементов
  с полярностью, цвет.
- Подписи набираются как в учебниках: буква курсивом с нижним индексом (`R₁`, `E₂`, `J₃`).
  Штрихи вводятся обычными апострофами и нормализуются в `′` и `″` — получается `R′₄`, `R″₆`.
- Подпись можно оттащить мышью от элемента: смещение сохраняется в файле.
- У диагональных элементов подпись сама встаёт по нормали к оси символа,
  а у зажимов — сбоку от кружка (`○ 1`, `○ 1′`), как в лабораторных.
- При множественном выделении поля показывают общее значение или прочерк,
  а изменение применяется сразу ко всем выбранным объектам.

### Выделение, выравнивание, буфер обмена

- Клик выделяет объект, `Shift+клик` добавляет или убирает его из выделения.
- Рамка-лассо по пустому месту выделяет всё, что в неё попало; с `Shift` — добавляет.
- `Ctrl+A` выделяет всё: элементы, провода, подписи и штрихи карандаша.
- Стрелки сдвигают выделенное на шаг сетки, со `Shift` — на 1 px.
- Шесть режимов выравнивания (по левому, правому, верхнему, нижнему краю и по центрам)
  и распределение по горизонтали и вертикали — появляются, когда выбрано 2+ (для
  распределения 3+) элемента.
- `Ctrl+C` / `Ctrl+V` и `Ctrl+D` работают с любым набором объектов: копия появляется
  со сдвигом в две клетки и сразу становится выделенной. Провода, привязанные к
  скопированным элементам, копируются вместе с привязками.
- `Delete` / `Backspace` удаляет выделенное; провода, потерявшие элемент, остаются
  на месте — просто без привязки.

### Провода

- Инструмент «Провод» (`W`): клик начинает линию, следующий клик ставит излом,
  `Enter` или двойной клик завершают, `Esc` отменяет.
- Маршрутизация «коленом»: сегмент строится по ортогонали, `Tab` переключает,
  идти сначала по горизонтали или по вертикали.
- `Shift` даёт прямой сегмент с шагом 45°, а если курсор на выводе — точное попадание в вывод.
- Режим свободного угла включается кнопкой в нижней панели или в свойствах —
  для векторных диаграмм и схем-«ромбов».
- Клик по выводу элемента **привязывает** конец провода: при перемещении элемента
  провод тянется за ним.
- Готовый провод редактируется мышью: сегмент можно перетащить целиком,
  конец — отвести в другую точку; лишние коллинеарные точки убираются автоматически.
- Соединения обозначаются жирными точками автоматически: анализ связности решает,
  где провода действительно сходятся, а где просто пересекаются.
- Стиль пересечений без соединения переключается: простое пересечение или
  полукруглая перемычка-«горбик».

### Подписи и аннотации

- Инструмент «Текст» (`T`) ставит свободную подпись в любом месте: узлы `a`, `b`, `c`,
  пояснения, номера участков. Настраиваются размер (8–48), курсив и цвет.
- Отдельная категория аннотаций: стрелка тока, стрелка напряжения, дуга обхода контура,
  вектор (поворачивается с шагом 45°) и оси `+1 / +j` для векторных диаграмм.
- В подписях работает та же нормализация штрихов, что и в обозначениях элементов.

### Карандаш

- Инструмент `P` рисует от руки поверх схемы — пометки преподавателю, стрелки на
  разборе, выделение контура обхода.
- Цвет (шесть готовых плюс произвольный) и толщина (1–16 px) настраиваются прямо
  в нижней панели, пока карандаш активен.
- Штрих прореживается при сохранении, попадает в историю одной записью, выделяется,
  двигается, копируется и экспортируется наравне с остальной графикой.

### История изменений

- `Ctrl+Z` / `Ctrl+Shift+Z` (и `Ctrl+Y`) — до **120 шагов** назад.
- История транзакционная: перетаскивание десяти элементов или рисование одного штриха
  — это одна запись, а не сотня промежуточных состояний.
- Кнопки отмены и повтора в левом верхнем бабле гаснут, когда откатывать нечего.

### Анализ схемы

Раздел меню «Схема» → «Проверка схемы» считает связность методом объединения множеств
и показывает:

- **электрические узлы** — сколько независимых потенциальных точек в схеме;
- **узлы с тремя и более ветвями** — то, что нужно для метода узловых потенциалов;
- **связные фрагменты** — сигнал, что часть схемы забыли подключить;
- **висящие выводы** — вывод элемента, никуда не подключённый;
- **повторяющиеся обозначения** — два `R3` в одной схеме.

Клик по замечанию выделяет виновника и центрирует на нём полотно. Те же счётчики
узлов видны в строке состояния всё время, без открытия диалога.

### Список элементов

Меню «Схема» → «Список элементов»: таблица «Обозначение — Тип — Значение», отсортированная
естественной сортировкой (`R2` перед `R10`). Элементы без обозначения (узлы, земля,
аннотации) в спецификацию не попадают. Кнопка «Копировать» кладёт таблицу в буфер
обмена с табуляцией — вставляется в Word и Excel готовой таблицей.

### Хранение схем и файлы

- **Автосохранение** в `localStorage` с задержкой 700 мс после последнего действия;
  при следующем открытии редактор восстанавливает последнюю схему.
- **Менеджер схем** («Мои схемы»): сетка карточек с векторными миниатюрами,
  бейдж «открыта» на текущей, поиск по названию, сортировка (сначала недавние,
  по названию, по размеру схемы). У каждой карточки меню: открыть, переименовать
  на месте, дублировать, скачать `.json`, удалить (с подтверждением; текущую схему
  удалить нельзя). Из футера — импорт файла и создание новой схемы.
- **Сохранение в файл** (`Ctrl+S`) открывает диалог: имя файла, число элементов,
  проводов, подписей и штрихов, итоговый размер в байтах — и только потом скачивание.
- **Импорт**: через меню, перетаскиванием `.json` прямо на полотно или из менеджера.
  Файл можно открыть как новую схему или вставить в текущую со сдвигом — второе удобно,
  когда типовой фрагмент переносится между работами.
- **Устойчивый разбор**: элементы с неизвестным типом, провода короче двух точек,
  битые ссылки на выводы и мусор в числовых полях отбрасываются, а не роняют импорт;
  список замечаний показывается в диалоге. Несовпадение версии формата даёт понятное
  сообщение.

Ключи в `localStorage`: `elshemas.index` (список схем), `elshemas.doc.<id>` (сами схемы),
`elshemas.current` (последняя открытая), `elshemas.settings` (настройки интерфейса).
В приватном режиме браузера, когда хранилище недоступно, редактор продолжает работать —
просто без автосохранения.

### Экспорт и печать

- **PNG** с масштабом 1×, 2× или 4× — для вставки в отчёт достаточно 2×.
- **SVG**, самодостаточный: вычисленные стили инлайнятся в атрибуты, файл открывается
  в Inkscape, Word и браузере без потери шрифтов.
- Фон белый или прозрачный, поля настраиваются в пикселях.
- Режим **«только выделенное»** — выгрузить один узел или фрагмент схемы.
- Предпросмотр с итоговым размером в пикселях до скачивания.
- Сетка, рамка выделения и служебная графика в экспорт не попадают.
- **Печать** (`Ctrl+P`): плавающие панели скрываются правилами `@media print`,
  на лист уходит только схема.

### Оформление и настройки

- Светлая и тёмная темы: палитра построена на CSS-переменных, тема переключается
  из меню «Вид» и запоминается.
- Настройки, которые переживают перезагрузку: тема, привязка и видимость сетки,
  стиль катушки, стиль пересечений, режим углов провода, цвет и толщина карандаша.
- Собственные подсказки к кнопкам вместо браузерных — появляются почти мгновенно.
- Тосты подтверждают действия: «Файл схема.json сохранён», «PNG сохранён», «Таблица скопирована».

### Доступность

- Все кнопки-иконки имеют имена (`aria-label`), переключатели — `aria-pressed`,
  панели — `aria-label` с названием области.
- Модальные окна удерживают фокус внутри себя (`Tab` не уходит на страницу) и закрываются `Esc`.
- Горячие клавиши не срабатывают, пока фокус в поле ввода или открыт диалог.

## Формат файла схемы

Файл `.json` — человекочитаемый снимок документа с отступами. Поле `version`
проверяется при импорте; при несовпадении выводится понятное сообщение, а не ошибка.
Текущая версия — 2; файлы версии 1 открываются как прежде и получают настройки
расчёта по умолчанию.

```jsonc
{
  "version": 2,                     // файлы версии 1 тоже открываются
  "title": "Мостовая схема",
  "grid": 20,                       // шаг сетки: 10, 20 или 40
  "analysis": {                     // настройки расчёта; в файлах версии 1 их нет
    "enabled": true,                // считать схему и показывать результаты
    "mode": "dc",                   // режим расчёта
    "frequency": 50,                // Гц, зарезервировано под переменный ток
    "showCurrents": true,
    "showVoltages": false,
    "showPowers": false,
    "showPotentials": false,
    "thickByCurrent": false,        // толщина провода по величине тока
    "signedCurrents": false,        // знак тока вместо разворота стрелки
    "digits": 4,                    // значащих цифр в подписях
    "reference": { "x": 60, "y": 260 }  // необязательно: опорный узел
  },
  "variables": { "R": "100", "Rn": "2*R" },   // переменные схемы
  "elements": [
    {
      "id": "el-1",
      "type": "resistor",           // тип из библиотеки УГО, см. таблицу ниже
      "x": 160, "y": 60,            // якорь, кратен шагу сетки
      "rotation": 0,                // 0 | 45 | 90 | 135 | 180 | 225 | 270 | 315
      "mirrored": false,
      "label": "R′1",               // штрихи можно вводить как ' и ''
      "value": "100",               // число, «2.2k», «4м7» или выражение «2*R»
      "unit": "Ом",
      "showValue": true,
      "polarity": "forward",        // необязательно: forward | reverse
      "labelOffset": { "x": 0, "y": -8 },  // необязательно: ручной сдвиг подписи
      "color": "#2563EB"            // необязательно: иначе цвет темы
    }
  ],
  "wires": [
    {
      "id": "w-1",
      "points": [{ "x": 200, "y": 60 }, { "x": 280, "y": 60 }],
      "from": { "elementId": "el-1", "portIndex": 1 },  // необязательно
      "to":   { "elementId": "el-2", "portIndex": 0 },  // необязательно
      "color": "#111827"                                 // необязательно
    }
  ],
  "labels": [
    { "id": "t-1", "x": 60, "y": 40, "text": "a", "fontSize": 16, "italic": true }
  ],
  "strokes": [
    {
      "id": "s-1",                  // рисунок карандашом поверх схемы
      "points": [{ "x": 10, "y": 10 }, { "x": 24, "y": 18 }],
      "width": 3,
      "color": "#e11d48"
    }
  ]
}
```

Разбор устойчив к повреждённым файлам: элементы с неизвестным `type`, провода
короче двух точек и битые ссылки на выводы отбрасываются, о чём сообщается
в диалоге импорта. Импорт предлагает открыть файл как новую схему или вставить
его в текущую.

## Типы элементов

**Пассивные:** `resistor`, `resistorVar`, `resistorTrim`, `resistorNonlinear`,
`capacitor`, `capacitorPol`, `inductor`, `mutualInductance`.

**Источники:** `sourceEmf`, `sourceCurrent`, `sourceVoltage`, `battery`, `sourceAc`,
`sourceThreePhase`.

**Измерительные:** `ammeter`, `voltmeter`, `wattmeter`.

**Коммутация:** `switchOpen`, `switchClosed`, `fuse`, `ground`, `junction`, `terminal`.

**Полупроводники:** `diode`, `zener`, `led`, `thyristor`, `transistorNpn`,
`transistorPnp`, `transistorFet`.

**Логические (ГОСТ 2.743):** `logicAnd`, `logicOr`, `logicNot`, `logicNand`, `logicNor`,
`logicXor`.

**Блоки:** `opamp`, `transformer`, `quadripole`.

**Аннотации:** `currentArrow`, `voltageArrow`, `loopArrow`, `vector`, `axes`.

Выводы двухполюсников расположены на расстоянии 40 px от якоря, поэтому при шаге
сетки 10, 20 или 40 они всегда попадают в узлы сетки.

## Чего в редакторе нет

Расчёт пока только для **цепи постоянного тока**. Не считаются:

- цепи переменного тока в комплексных амплитудах, а с ними — реактивные
  сопротивления, полная и реактивная мощность, cos φ;
- переходные процессы и частотные характеристики;
- нелинейные элементы: диоды, стабилитроны, транзисторы (они исключаются из расчёта,
  о чём сказано в замечаниях);
- многополюсники: трансформаторы, взаимная индуктивность, операционные усилители.

Векторные диаграммы строятся вручную: для них есть оси `+1 / +j` и вектор,
который поворачивается с шагом 45°. Вывод системы уравнений на бумагу
(методом контурных токов или узловых потенциалов) и генератор отчёта тоже
пока не реализованы.

## Структура проекта

```
src/
  types/schema.ts          Модель данных: SchemaFile, Element, Wire, TextLabel, Stroke
  symbols/                 Библиотека УГО
    registry.ts            Каталог символов: порты, габариты, значения по умолчанию
    primitives.tsx         Общие SVG-примитивы (выводы, стрелки, дуги катушек)
    defs/                  Описания символов по категориям
    shapes/                Сами УГО, сгруппированные по категориям
  lib/
    solver/                Расчётное ядро, не зависит от интерфейса
      model.ts             Чем является символ с точки зрения уравнений цепи
      graph.ts             Схема → узлы и ветви
      mna.ts               Модифицированный метод узловых потенциалов
      linalg.ts            LU-разложение с выбором главного элемента
      dc.ts                Токи, напряжения, мощности, баланс
    expr.ts                Вычислитель выражений в значениях элементов
    units.ts               Инженерные приставки и форматирование величин
    variables.ts           Таблица переменных схемы
    share.ts               Схема в ссылке: сжатие и хеш адреса
    geometry.ts            Габариты, порты, попадание в сегмент
    ortho.ts               Ортогональная маршрутизация проводов
    nodes.ts               Связность: узлы, точки соединения, фрагменты
    crossings.ts           Пересечения проводов и перемычки
    validate.ts            Проверка схемы
    autonumber.ts          Автонумерация обозначений по префиксам
    mutations.ts           Перенос, поворот, выравнивание, копирование фрагментов
    commands.ts            Команды меню и горячих клавиш
    fileIO.ts              Сериализация, разбор, скачивание файлов
    storage.ts             localStorage: список схем, автосохранение
    exportImage.ts         Построение SVG и растеризация в PNG
    viewport.ts            Масштаб, панорамирование, вписывание в экран
  store/
    useDoc.ts              Документ и история (undo/redo, транзакции перетаскивания)
    useUi.ts               Вид, инструмент, выделение, настройки, диалоги
  components/
    canvas/                Полотно, слои схемы, обработка указателя
    dialogs/               Экспорт, менеджер схем, импорт, проверка, список, справка
    ui/                    Переиспользуемые попапы и меню
  hooks/                   Горячие клавиши, автосохранение, тема, автопересчёт
tests/
  solver.test.ts           Расчёт на схемах с известным аналитическим ответом
```

Каждый компонент лежит в отдельном файле, самый длинный файл проекта — около 300 строк.

Полотно рисуется инлайновым SVG: элементы мемоизированы, анализ связности
откладывается через `useDeferredValue`, поэтому перетаскивание схемы из
200 элементов и 370 проводов держится в пределах 8 мс на кадр.
